# nvim-config

LazyVim setup with a custom mono theme (`:MonoToggle`, `Space u M`).

## Restore

    sudo pacman -S --needed neovim git base-devel ripgrep fd unzip tree-sitter-cli nodejs npm python python-pip lazygit wl-clipboard ttf-jetbrains-mono-nerd gcc
    git clone https://github.com/Crysisto/nvim-config.git ~/.config/nvim
    nvim
